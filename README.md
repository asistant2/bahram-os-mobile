# BAHRAM OS — برنامه‌ریز شخصی موبایل

یک PWA فارسی و راست‌چین برای استفادهٔ روزمره از گوشی.

## قابلیت‌ها
- برنامهٔ امروز با حداکثر سه اولویت اصلی، پیشرفت واقعی و قدم بعدی.
- صندوق ثبت سریع برای کارها، ایده‌ها و پیگیری‌ها.
- پروژه‌ها، موعد نهایی، اولویت، تخمین زمان، تسک‌های تحویل و فیلترها.
- رویدادهای زمان‌دار برای فیلم‌برداری، عکاسی، جلسه و قرارهای شخصی؛ ساخت خودکار تسک آماده‌سازی در روز قبل.
- برنامه‌ریزی هفتگی با ظرفیت جداگانه برای هر روز، در نظر گرفتن موعد، اولویت و مدت تخمینی؛ کارهای جا‌نشده در صندوق می‌مانند و حذف نمی‌شوند.
- بخش Planning Desk برای پیام‌های فارسی رایج: تعیین ظرفیت امروز، ثبت ضرب‌الاجل، رویداد، انرژی، وزن، تمرین زبان/حرکت، سیگار، بازچینی هفته و گزارش.
- عادت‌ها با ثبت روزانه و شمارش استمرار، تایمر تمرکز و گزارش هفتگی.
- خروجی پشتیبان JSON؛ داده‌های کاربر روی همان دستگاه ذخیره می‌شوند.

## نصب روی گوشی
بازکردن GitHub Pages در Chrome، منو ⋮، سپس Install app یا Add to Home screen.

## نکتهٔ مهم دربارهٔ هوش مصنوعی و یادآوری‌ها
این نسخه به سرویس مدل زبانی متصل نیست. بخش Planning Desk بر اساس قواعد محلی و الگوهای فارسی کار می‌کند؛ بنابراین هر جملهٔ پیچیده‌ای را مانند یک چت‌بات مولد نمی‌فهمد. خودکارسازی پس‌زمینه و اعلان زمان‌بندی‌شده هم فعلاً فعال نیست. برای این قابلیت‌ها باید یک backend امن یا سرویس اتصال جداگانه راه‌اندازی شود؛ کلید API نباید در HTML عمومی قرار گیرد.

## حریم خصوصی
کارها، پروژه‌ها، گزارش‌ها و عادت‌ها در localStorage همان مرورگر ذخیره می‌شوند و توسط این صفحه به GitHub ارسال نمی‌شوند. در بخش گزارش از اطلاعات پشتیبان بگیر. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات ذخیره‌شده را حذف کند.

## سازگاری داده
از کلید ذخیره‌سازی قبلی bahram-os-mobile-v1 استفاده می‌شود تا داده‌های نسخهٔ اول از دست نروند. قبل از به‌روزرسانی اصلی، از گزارش فایل پشتیبان بگیر.
