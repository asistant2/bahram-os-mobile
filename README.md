# BAHRAM OS — مربی شخصی موبایل

اپ فارسی و موبایل‌محور برای برنامه روزانه، پیگیری کار، زبان، وزن، ورزش، انرژی و ثبت سیگار.

## راه استفاده
1. سایت GitHub Pages را روی گوشی باز کن.
2. در اندروید، منوی Chrome را باز کن و **Install app** یا **Add to Home screen** را بزن.
3. هر روز از تب «امروز» شروع کن. برای ثبت کار از «کار جدید» یا کادر ثبت سریع استفاده کن.
4. از «گزارش» خروجی روز و از «پشتیبان داده» فایل JSON بگیر.

## دستورهای سریع فارسی
- \`کار جدید: تدوین ۱۰ شات اول\`
- \`انجام شد: تمرین ارمنی\`
- \`امروز فقط ۹۰ دقیقه وقت دارم\`
- \`برنامه عوض شد، از ۱۴ تا ۲۰:۳۰ بیرونم\`
- \`انرژی ۲ از ۱۰\`
- \`وزنم ۱۰۲\`
- \`ورزش کردم ۳۰ دقیقه\`
- \`ارمنی ۲۰ دقیقه تمرین کردم\`
- \`سیگار\`
- \`گزارش روز\`

دستورهای متنی با چند الگوی ساده اجرا می‌شوند؛ این نسخه به مدل هوش مصنوعی متصل نیست. اگر جمله‌ای تشخیص داده نشود، آن را به‌عنوان یک کار جدید ذخیره می‌کند.

## حریم خصوصی
تمام داده‌ها در \`localStorage\` مرورگر همان دستگاه ذخیره می‌شوند و به سرور یا GitHub ارسال نمی‌شوند. اگر داده‌های مرورگر را پاک کنی، ممکن است اطلاعات از بین بروند؛ مرتب از فایل پشتیبان استفاده کن. این نسخه هنوز همگام‌سازی بین چند دستگاه، پردازش آزاد زبان با AI یا یادآوری پس‌زمینه ندارد.

## توسعه
این یک PWA ایستا است. تغییرات عمومی مخزن فقط کد اپ را تغییر می‌دهد، نه رکوردهای ذخیره‌شده در گوشی.
